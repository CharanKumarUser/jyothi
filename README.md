- **SEO & Social Share Ready**: OpenGraph metadata, Twitter Cards, and schema.org `Physician` structured JSON-LD for Google rich snippets.

### 2. WWW Subdomain (`www.jyothi.online`) — CNAME Record
Add a `CNAME` record for `www`:

| Type | Host / Name | Value | TTL |
|---|---|---|---|
| **CNAME** | `www` | `charankumaruser.github.io` | Automatic / 3600 |

### 3. GitHub Pages Settings
1. Go to your repository on GitHub: `https://github.com/CharanKumarUser/jyothi`
2. Click **Settings** > **Pages**.
3. Under **Build and deployment**, select **GitHub Actions** (or Deploy from a branch: `main` / `root`).
4. Ensure **Custom domain** shows `jyothi.online`.
5. Check **Enforce HTTPS** (GitHub automatically generates a free Let's Encrypt SSL certificate within a few minutes of DNS verification).
